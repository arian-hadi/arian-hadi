## About

I am a software engineer and full stack developer focused on building dependable web products from backend architecture and APIs to user-facing interfaces and deployment. My experience spans **Django, .NET, React, Next.js, PostgreSQL, SQL Server, Docker, and CI/CD**, with hands-on work across multi-tenant systems, marketplace platforms, AI-enabled applications, and data-driven products.

I approach engineering with a product mindset: understand the real problem, design maintainable systems, ship useful features, and keep the application stable after deployment. I have also worked with **OpenAI, Gemini, and Anthropic APIs**, as well as applied machine learning tools including **PyTorch, Scikit-learn, Hugging Face, and BERT tokenization**.

I am currently pursuing a **Master's degree in Computer Engineering** and continuing to deepen my skills in scalable backend systems, applied AI, cloud infrastructure, and software architecture.
